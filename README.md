# Claude AI powered code reviewer

*Features
- Paste any code segment (Java, Python, C, JavaScript, etc)
- Get specific feedback with labeled line numbers
- Identifies bugs, performance issues, and room for improvements
- Simple, easy-to-use interface

*Live Link
- https://pr-review-cli.vercel.app/

*Tech Stack
- Frontend: JavaScript, CSS, HTML
- Backend: Flask (Python)
- Claude API (Anthropic)
